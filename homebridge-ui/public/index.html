Paperclip connects your Samsung air conditioner to HomeKit through SmartThings, the app your AC already uses. Setup takes about three minutes and happens once.

Step 1 · Create Paperclip's SmartThings app

SmartThings needs a small private "app" in your account that Paperclip signs in through. Paperclip can make it for you.

  1. Open account.smartthings.com/tokens and sign in with your Samsung account.
  2. Click Generate new token, call it paperclip, tick every scope, then Generate token.
  3. Copy the token and paste it here. It is only used once to create the app, and is not saved.

Use this if the quick option fails, or if you created an OAuth-In app with the SmartThings CLI.

How to create the app with the SmartThings CLI
  1. On the Homebridge machine run brew install smartthingscommunity/smartthings/smartthings
  2. Save the JSON below as paperclip-app.json
  3. Run smartthings apps:create -i paperclip-app.json and sign in when the browser opens
  4. Copy the OAuth Client Id and OAuth Client Secret it prints into the fields above
Step 2 · Let Paperclip control your AC
  1. Open SmartThings sign-in
  2. Sign in, choose the location your air conditioner is in, then tap Authorize.
  3. You land on a plain page from httpbin.org. Copy the whole address from the address bar (it contains ?code=) and paste it here.

The code only works for a few minutes. If Connect fails, open the sign-in link again.

Connected to SmartThings

Next: click Save below and restart Homebridge if it asks. Your AC then appears in the Home app on your iPhone. If you haven't added Homebridge to the Home app yet, scan the QR code on the Homebridge status page.
